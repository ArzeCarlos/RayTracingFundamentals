# Ray Tracing Fundamentals

A basic **ray tracer implemented from scratch in C++**, developed to explore the fundamentals of **Ray Tracing** and **Computer Graphics**.

The project implements a 3D scene using rays, vectors, spheres, materials, a virtual camera, and random sampling, generating the final image in `.ppm` format.

## ✨ Features

- Ray tracing from scratch in C++
- 3D vectors and mathematical operations
- Rays and ray-object intersections
- Spheres as renderable objects
- Lambertian materials
- Diffuse reflection
- Multiple ray bounces
- Anti-aliasing using multiple samples per pixel
- Virtual camera
- `.ppm` image generation
- Makefile-based compilation

## 🛠️ Technologies

- **C++**
- **GNU Make**
- **PPM (Portable Pixmap)**

## 📋 Requirements

Make sure you have the following installed:

- C++ compiler (`g++`)
- `make`
- `Git`

### Windows

On Windows, you can use **MinGW** or **MSYS2** to install and use `g++` and `make`.
